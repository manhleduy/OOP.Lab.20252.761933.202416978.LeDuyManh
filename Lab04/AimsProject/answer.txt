B: Suppose the DVDs has a different ordering rule from the other media types, that is by title, then decreasing
length, then cost. How would you modify your code to allow this?
A: we can use these following code
@Override
public int compareTo(DVD other) {
    int titleCompare = this.title.compareToIgnoreCase(other.title);
    if (titleCompare != 0) return titleCompare;

    int lengthCompare = Integer.compare(other.length, this.length); // Descending length
    if (lengthCompare != 0) return lengthCompare;

    return Double.compare(this.cost, other.cost);
}
